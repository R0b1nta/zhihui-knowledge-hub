# 全站第二轮设计与借鉴

日期：2026-10-26。版本：0.4.0。

以上为产品与交互借鉴，前端实现为本项目独立代码。

## 全站视觉

- 底色使用近白与浅冷灰，正文深色，蓝灰用于交互提示；去除旧版大面积浅绿色与金色装饰。
- 首页与内页统一品牌符号、轻导航、边框、按钮和字体层级。文库、搜索、项目、管理后台与弹窗采用同一套样式。
- 阅读标题使用设备上的宋体系列，正文使用系统字体；不加载外部字体、CDN、统计或第三方脚本。
- 文库默认列表，可切换卡片；分类、关键词、排序与显示方式进入地址参数，阅读返回时保持上下文。
- 手机内页使用导航抽屉与折叠文章目录，减少横向拥挤。

## 动效与回退

`public/clouds.js` 是独立的前景雾层模块，以较低画布分辨率、多层噪声与透明合成营造深浅变化，最多约 25 次绘制/秒。鼠标移动、云量、流速与景深设置影响雾层。它是视觉近似，不是物理云层模拟。

背景使用 0.3.0 已生成的 `public/assets/cimai-mountains.jpg`。本轮尝试生成新背景遇到限流，没有产生或使用新的背景文件。

系统要求减少动态效果、点击暂停、页面隐藏或首屏离开视口时停止相应动画；离开首页时销毁 WebGL 资源与监听。WebGL 不可用时显示静态背景与 CSS 回退。设置控件具有标签、键盘操作与关闭入口。

## 文章排版

支持段落、一级至三级 Markdown 标记、中文“一、二、三”章节、无序列表、引用、代码块、HTTP(S) 外链与简单表格。文章标题仍由文章字段提供；正文的 `#` 与 `##` 作为二级标题、`###` 作为三级标题。

所有原始 HTML、属性字符、代码内容和表格单元格均转义；链接仅允许 HTTP 与 HTTPS。不是通用 HTML 编辑器，不支持任意 HTML、脚本或内嵌组件。已有纯文本正文不被改写，保存与数据库结构均沿用原行为。

本页目录、阅读进度、相关分类导航、复制链接和打印视图使用同一份正文。相关文章优先同分类，上一篇/下一篇沿用现有文章顺序；阅读时间为按字数估计。

## 验证范围

20 项测试覆盖原有登录/退出、账号停用、项目与管理员权限、数据库持久化、搜索排序和分页、旧站导入、新资源路由，以及新排版的 HTML 转义、链接限制、目录兼容和相关文章排序。

另用独立本机预览数据人工检查桌面与手机页面、云量调节、减少动态效果、分类抽屉、分类/关键词/视图返回、旧文章阅读、临时管理员登录、Markdown 预览及保存。临时账号和排版示例不进入交付或线上数据库。
