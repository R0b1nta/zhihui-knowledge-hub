# 山水版 V2.0

2026-10-31。山水方案的第二版，网站名称仍为“磁脉”。版本号用于代码与设计存档，不增加首页角标。

## 设计计划

- 色彩沿用山峦蓝 `#203d47`、深海蓝 `#193540`、雾白 `#f8faf6`、冷灰 `#eff3f2`、岩灰 `#61767a`。
- 字标采用汉隶的扁阔字形、波磔和横向舒展，以现代简体“磁脉”呈现。它是现代隶书字标，不标称某位古人真迹。正文和导航保留现有字体，确保阅读清楚。
- 构图：轻导航 → 云海中央的宽幅白色字标 → 两组四字短句 → 底端探索入口。桌面居中，手机按可用宽度缩放，不把字拆成两行。
- 唯一主要改动是字标。保留山体、云雾与滚动景深，不增加印章、朝代标签或装饰英文。

审视：采用横向、低重心的隶书轮廓呼应山脊，而非给普通网页大标题换一个字体；不增加一套与公司技术无关的装饰。

## 字标与文案

- 标题：磁脉。输出为两字合成的一幅 SVG 路径图形，无 SVG text 节点、无网页字体文件，不能以普通文字拖选复制；可访问名称保留“磁脉”。图形仍可被截图或保存，不属于防复制加密。
- 短句：**驭磁成器，聚脉成章**。前者指向磁场工程应用，后者呼应知识积累成文；不是技术性能承诺。
- 删除山水首页的 Cimai 英文副标。
- 字形图形由本机 Windows 自带 LiSu（隶书）排版生成，仅输出完整词组图形，不分发、嵌入或修改字体文件。微软允许使用系统字体制作公司标志和文字图形：[Font redistribution FAQ](https://learn.microsoft.com/en-us/typography/fonts/font-faq)。

## 保留的行为

北京时间周六、周日显示山水首页；日期仍来自访客设备时钟并转换为 Asia/Shanghai。公开文章、搜索、项目空间、后台和工作日磁脉首页共用原有内容与权限。
