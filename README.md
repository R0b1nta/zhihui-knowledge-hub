# 磁脉知识库

面向小团队的企业知识与项目空间。部署目标是用户现有的阿里云轻量服务器，不依赖 Sites 托管、外部字体、CDN 或第三方账号。

## 当前版本

- 首页：山海全屏开场、缓慢镜头与云雾动效、三项技术方向切换，连接现有知识文库和项目空间；支持暂停与减少动态效果。
- 公开：文章全文、分类筛选、全文搜索，适配手机和电脑。
- 文章使用独立详情页，左侧导航保持一致；地址可直接打开与刷新，从搜索进入后可返回原搜索结果。
- 全局搜索：任意页面顶部搜索或按 Ctrl+K，支持文章正文、项目说明、负责人、状态和截止日期；多关键词同时匹配、相关度排序、关键词高亮、分页与详情跳转。访客仅搜索公开文章。
- 员工：个人账号登录、查看和新建项目、更新负责人 / 截止日期 / 状态 / 项目说明。
- 管理员：发布 / 编辑 / 删除公开文章；开通 / 停用员工账号、重设密码；删除项目。
- 所有员工共享项目空间；暂不支持项目级成员权限、附件、任务子项、评论、审批、通知、AI 问答。
- SQLite 持久保存数据；密码使用 scrypt 加盐哈希，登录会话最长 8 小时。
- 默认不开放访客注册，不设默认密码。首次仅创建明确标注的示例文章，不创建员工或内部项目。
- 旧站内容参考：已整理 7 篇公司与技术介绍。管理员在“内容与账号 → 旧站参考内容”中预览后导入；不自动发布，不覆盖现有文章，重复导入不会增加副本。

## 本机预览

需要 Node.js 24 或更新版本，无第三方运行依赖，无需安装依赖包。

PowerShell：

```powershell
$env:SESSION_SECURE='0'
npm start
```

打开 http://127.0.0.1:3100 。此模式只允许绑定本机，用于本地体验登录。

另一个终端在同一项目目录运行以下命令，按提示创建管理员。输入密码时不会显示字符：

```text
npm run admin
```

管理员登录后在“内容与账号”开通员工账号。公开文章保存后立即对访客可见。

## 阿里云部署

见 [部署指南](DEPLOY.md)。没有域名时先通过公网 IP 的 3100 端口试运行公开知识库；公网员工登录需域名与 HTTPS 就绪。已有 WordPress 不会被本项目自动修改或卸载。

## 数据与备份

默认数据文件为 `data/hub.sqlite`，可通过 `DATA_DIR` 更换目录。数据目录不被 Web 服务器静态提供，也已从 Git 排除。

```text
node scripts/backup.mjs
```

使用 SQLite 在线备份 API 生成一致性备份；不要只复制正在写入的 `.sqlite` 主文件。备份包含内部项目与账号哈希，应私密保存。建议每天备份，并复制到服务器之外；保留周期按公司需要设置。

恢复时先停止应用，把备份复制为目标数据目录的 `hub.sqlite`，移走旧的 `hub.sqlite-wal` / `hub.sqlite-shm`，恢复目录权限后重启。恢复到新目录验证成功后再切换正式目录。
