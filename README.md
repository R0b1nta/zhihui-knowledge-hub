# 磁脉知识库

面向小团队的企业知识与项目空间。部署目标是用户现有的阿里云轻量服务器，不依赖 Sites 托管、外部字体、CDN 或第三方账号。

## 当前版本：0.5.0

- 全站：统一品牌、冷灰底色、字体、导航、按钮与表单；涵盖首页、文库、文章、搜索、员工项目和管理后台。
- 默认首页：定制矢量字标、导电纹理与通电交互、公开技术知识网络；子标题使用受楞次定律启发的“来拒去留”响应，靠近退让、离开跟随、静止消退，链接的点击区域保持固定。它是交互隐喻，不是磁场数值模拟。
- 字标通电：默认每 8 秒自动触发，点击“通电设置”可暂停自动、调节 5–20 秒间隔、0.75–1.75 倍速度、40–140% 亮度，并选择脉冲扫描或双向汇流；支持手动预览、恢复默认和浏览器偏好保存。自动脉冲保留所选知识主题；设置面板打开、字标离开视野、切到后台、关闭动效或系统减少动态效果时暂停，不补播积压动画。
- 首页外观：按北京时间自动安排，周一至周五显示磁脉，周六、周日显示山水；不向访客显示外观选择入口或弹窗，也不使用以前保存的主题偏好。每次进入首页时确定当天外观，阅读文章期间不主动切换；两种外观共用文章、搜索和项目数据。旧 `#landscape` 链接回到统一首页并遵循日期安排。
- 山水外观：保留全屏山海、WebGL 前景雾层与云海设置；支持暂停、减少动态效果、隐藏时停绘及静态回退。历史源码保存在 Git 分支 `archive/landscape-20261027`。
- 文库：侧栏分类与计数，列表/卡片切换、排序；分类、关键词与显示方式保存在地址中。
- 公开：文章全文、分类筛选、全文搜索，适配手机和电脑。
- 文章：独立阅读页，左侧导航保持一致；支持章节目录、阅读进度、相关文章、上一篇/下一篇、复制链接和打印。已有中文章节标题可生成目录，新增正文可使用安全的 Markdown 子集；后台可预览排版。地址支持刷新，并保留来源筛选或搜索上下文。
- 文章整理：后台可导入 UTF-8 TXT / Markdown 文字稿，支持撤销导入；提供章节标题、小节标题、重点、列表与提示工具。整篇预览同时显示主标题、内容概要和文章结构，导入不会自动公开发布。
- 全局搜索：任意页面顶部搜索或按 Ctrl+K，支持文章正文、项目说明、负责人、状态和截止日期；多关键词同时匹配、相关度排序、关键词高亮、分页与详情跳转。访客仅搜索公开文章。
- 员工：个人账号登录、查看和新建项目、更新负责人 / 截止日期 / 状态 / 项目说明。
- 管理员：发布 / 编辑 / 删除公开文章；开通 / 停用员工账号、重设密码；删除项目。
- 所有员工共享项目空间；暂不支持项目级成员权限、附件、任务子项、评论、审批、通知、AI 问答。
- SQLite 持久保存数据；密码使用 scrypt 加盐哈希，登录会话最长 8 小时。
- 默认不开放访客注册，不设默认密码。首次仅创建明确标注的示例文章，不创建员工或内部项目。
- 旧站内容参考：已整理 7 篇公司与技术介绍。管理员在“内容与账号 → 旧站参考内容”中预览后导入；不自动发布，不覆盖现有文章，重复导入不会增加副本。

## 本机预览

需要 Node.js 24 或更新版本，无第三方运行依赖，无需安装依赖包。

PowerShell：

```powershell
$env:SESSION_SECURE='0'
npm start
```

打开 http://127.0.0.1:3100 。此模式只允许绑定本机，用于本地体验登录。

第一次使用本机预览时，打开 `/#admin`，在“开通管理员”页面设置账号、显示姓名和密码。开通后会自动登录，并关闭首次开通入口；随后可在“内容与账号”发布文章和开通员工账号。密码至少 12 个字符，无默认密码。

网页首次开通只在明确启用的本机 HTTP 预览中开放，且数据库必须没有任何账号。公网、HTTPS 生产配置、代理请求与已存在账号的实例不开放此入口；已停用的管理员也不会触发重新开通。部署服务器仍通过下面的命令创建管理员。

也可以在另一个终端的项目目录运行以下命令，按提示创建管理员。输入密码时不会显示字符：

```text
npm run admin
```

管理员登录后在“内容与账号”开通员工账号。公开文章保存后立即对访客可见。

## 阿里云部署

见 [部署指南](DEPLOY.md)。没有域名时先通过公网 IP 的 3100 端口试运行公开知识库；公网员工登录需域名与 HTTPS 就绪。已有 WordPress 不会被本项目自动修改或卸载。

更新时请完整保留 `public/electromagnetic-home.html`、`public/home-theme.js` 和 `public/editor.js`，并重启应用加载最新路由与静态资源配置。新版首页使用与主站同域的独立显示区域隔离样式，内部链接进入主站顶层路由；主题阅读链接根据当前公开文章目录解析，不绑定本机端口或固定数据库文章 ID。主应用页面继续禁止被嵌入，仅该首页资源允许同域显示。

## 如何录入和整理文章

管理员登录后，进入“内容与账号 → 发布文章”，也可以在知识文库中点击“发布文章”。先粘贴原文，或用“导入文字稿”选择 `.txt`、`.md`、`.markdown` 文件。文件仅在当前浏览器读入编辑器，点击公开发布前不会保存为公开文章；导入后可撤销。

Word / PDF 暂不直接转换或作为附件上传；可先复制文字，或在整理后保存为文字稿。文字稿需 UTF-8，单篇正文最多 30000 字。只有明确的第一行 Markdown 主标题会被拆到标题栏，普通段落不会被猜成标题，原始参数和措辞不会自动改写。

文章主标题回答“这篇解决什么问题”，摘要用两三句话交代主要结论、适用对象或阅读价值；正文用章节说明原理、方法、应用及边界。选中一行后点击“章节标题”或“小节标题”，选中关键文字后点击“加粗重点”。结构提示会显示已识别的标题数量；“预览整篇文章”可检查标题、摘要、目录和正文层级。

对不具备的信息不必补写。内容审阅完成后，再点击“公开发布”或“保存修改”；当前文库文章对所有访客可见，员工内部项目仍使用登录后的项目空间。

## 数据与备份

默认数据文件为 `data/hub.sqlite`，可通过 `DATA_DIR` 更换目录。数据目录不被 Web 服务器静态提供，也已从 Git 排除。

```text
node scripts/backup.mjs
```

使用 SQLite 在线备份 API 生成一致性备份；不要只复制正在写入的 `.sqlite` 主文件。备份包含内部项目与账号哈希，应私密保存。建议每天备份，并复制到服务器之外；保留周期按公司需要设置。

恢复时先停止应用，把备份复制为目标数据目录的 `hub.sqlite`，移走旧的 `hub.sqlite-wal` / `hub.sqlite-shm`，恢复目录权限后重启。恢复到新目录验证成功后再切换正式目录。
